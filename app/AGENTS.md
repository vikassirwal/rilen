# RILEN Agent Instructions

Before proposing or implementing major product, UX, architecture, or data-model decisions in this repository, read `../RILEN_CONTEXT.md`.

Treat `../RILEN_CONTEXT.md` as the source of truth for RILEN's product direction, UX philosophy, architecture principles, and current priority.

When making decisions, prefer the RILEN principles from that file:
- proactive and exception-driven workflows
- staff time saved over feature volume
- deterministic logic before AI
- auditability for financial operations
- multi-school SaaS foundations
- deep fee-management MVP before unrelated modules

When uncertain, ask:

> What manual work is the human still doing that RILEN should have done?
